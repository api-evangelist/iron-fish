# Iron Fish

> Iron Fish is a zero-knowledge Layer 1 blockchain delivering optional privacy for cryptocurrency transactions. Developers integrate through a self-hosted node RPC server (TCP/IPC/HTTP, JSON with streaming) and a hosted public REST API, with a first-party JavaScript SDK and the `ironfish` CLI.

## APIs

- [Iron Fish Public REST API](https://api.ironfish.network): Hosted block-explorer/faucet API; list envelope with cursor pagination (base https://api.ironfish.network).
- [Iron Fish Node RPC](https://ironfish.network/developers/documentation/integration_rpc): Self-hosted node RPC over TCP/IPC/HTTP; namespaces chain, wallet, node, peer, miner, config, event, mempool, worker.
